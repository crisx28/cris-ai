# Build Schedule Automation — Sequoya

Cross-team handoff documents for the Build Schedule automation project on
**Sequoya** (`built-by-dojo/dojo-dashboard` + `creative-club/dojo-agents`).

Unrelated to this repo's own product (`cris-ai` / `budget-os`, the Financial
Planning Platform). Stored here for durable version history only, at the
repo owner's request — not part of this codebase's application.

- `spec.html` — living handoff spec, source of truth for the automation
  project. Data sources, field ownership, open questions, known defects.
- `visual-audit.html` — grounded findings from live-app screenshots.
- `target-design.html` — early mockup, superseded by `final-layout.html`.
- `final-layout.html` — authoritative layout reference, current build
  target for the frontend owner. Includes the hover-detail interaction.

Each file is a standalone HTML page — open directly in a browser.
